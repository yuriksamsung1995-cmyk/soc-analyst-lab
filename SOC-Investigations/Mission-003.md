Mission 003 – SOC Investigation

1. Investigation Objective

Analyze Windows Security Events to identify suspicious account activity and potential security incidents.

2. Environment

* Operating System: Windows 11
* Analysis Tool: Windows Event Viewer
* Log Source: Windows Security Log

3. Events to Investigate

* Event ID 4624 – Successful logon
* Event ID 4625 – Failed logon
* Event ID 4672 – Special privileges assigned to new logon
* Event ID 4720 – User account created
* Event ID 4732 – Member added to a security-enabled local group

4. Investigation Tasks

1. Identify successful and failed logon attempts.
2. Check account names and logon types.
3. Identify potentially suspicious activity.
4. Determine whether administrator privileges were assigned.
5. Document findings and recommended actions.
